DeepSeek Harness Desktop

下载、安装、双击打开——就是 DeepSeek Harness，而且永远是最新版。
内置 Node.js 与 pnpm，无需任何前置环境。

下载安装包

三步开始

  1. 点击上方按钮下载 DeepSeek Harness Setup.exe（Windows 10/11，约 60MB）。
  2. 双击安装，然后打开应用——首次启动会自动下载 Harness 最新代码并安装依赖，需要几分钟，进度可见。
  3. 在界面「设置」中填入你的 DeepSeek API Key，开始使用。

每次启动自动检查 deepseek-ai/deepseek-harness 的最新提交，主仓更新即应用更新。
用户数据保存在 ~/.dsh，升级不影响。源码与说明见 GitHub 仓库。
